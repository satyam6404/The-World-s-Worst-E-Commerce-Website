# 🛒 MEGA WORST MART (Sab Kuch Bekaar)

Welcome to **MEGA WORST MART** — famously known as *"The World's Worst E-Commerce Website"*. 

Don't let the name fool you. While the website is intentionally designed to be a hilariously chaotic, frustrating, and absurd shopping experience for the user, the **underlying code is an excellent, fully-functional, and robust MERN-style architecture**.

Every annoyance, visual glitch, and weird feature is a meticulously designed joke, never an actual bug! 

---

## 🌟 Features (or "Anomalies")

*   **Absurd Products:** Buy a "Left Shoe (Only Left)" or "Premium Air (1 Litre, Sealed)"! 
*   **Dynamic Chaos Meter:** The UI gets progressively weirder and more chaotic based on the "Chaos Level."
*   **BekaarBot:** An offline chat widget that is totally useless but tries its best.
*   **Tilted UI & Clashing Colors:** A nostalgic nod to terrible 90s web design mixed with modern responsive CSS Grids.
*   **Fake Social Proof:** Popups claiming "Random Person from Delhi abhi abhi khareed raha hai."
*   **Hilarious T&Cs:** A checkout flow where the terms and conditions are completely unacceptable.
*   **Fully Functional Cart & Checkout:** Despite the chaos, the core e-commerce flow (browsing -> cart -> checkout -> order tracking) is 100% functional and bug-free.

---

## 🛠️ Tech Stack

*   **Frontend:** Vanilla JavaScript (ES6+), HTML5, and CSS3. Built as a Single Page Application (SPA) without heavy frameworks. 
*   **Backend:** Node.js with Express.js.
*   **Database:** JSON file-based persistence for lightweight, serverless-style data management.
*   **Auth:** JWT (JSON Web Tokens) for secure, stateless authentication.

## 🚀 Getting Started

Follow these steps to run the chaos locally on your machine:

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### 2. Installation
Clone the repository and install the backend dependencies:

```bash
git clone https://github.com/yourusername/SmartMart.git
cd SmartMart/backend
npm install
```

### 3. Run the Server
You can start the server using standard Node or Nodemon (for development):

```bash
# Standard start
npm start

# Or using Nodemon for hot-reloading
npm run dev
```

### 4. View the App
Once the terminal says `🔥 MEGA WORST MART running on http://localhost:3000`, open your favorite web browser and navigate to:

👉 **http://localhost:3000**
